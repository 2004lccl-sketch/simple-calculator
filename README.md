# 简易四则运算计算器

一个可在手机和电脑浏览器中使用的四则运算网页。项目使用原生 HTML、CSS 和 JavaScript 编写，无需安装依赖或运行服务器。

## 在线使用

网站地址：[https://2004lccl-sketch.github.io/simple-calculator/](https://2004lccl-sketch.github.io/simple-calculator/)

## 功能

- 支持加法、减法、乘法和除法
- 检查无效数字输入，并阻止除数为 0
- 显示最近 10 次计算记录，并可一键清空
- 支持在输入框中按 Enter 键计算
- 响应式布局，适配手机屏幕

## 使用方法

1. 在两个输入框中输入数字。
2. 选择 `+`、`−`、`×` 或 `÷`。
3. 点击“计算结果”，或在输入框内按 Enter。
4. 最近的计算会显示在“计算历史”中；点击“清空记录”可删除记录。

## 在 GitHub Pages 发布

1. 将本项目文件上传到 GitHub 仓库的根目录，确保入口文件名为 `index.html`。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/(root)` 目录并保存。
5. 等待 GitHub Pages 完成部署，然后从 Pages 设置页打开网站地址。
